# 分析方法：从证据到判断

## 1. 从证据到判断

每个强判断至少经过四步：

```text
原始材料
  -> 事实或信息抽取
  -> 共同指向/分歧识别
  -> 分析判断
  -> 信心和边界
```

不要把原文摘录、指标数字或标签直接当结论。

## 2. 判断强度

判断强度用于说明"证据支撑到哪里"，不是态度强弱。

| 强度 | 使用条件 | 写法 |
|------|---------|------|
| 支撑 | 多源证据共同指向，缺口不影响核心判断 | 当前证据支持判断为... |
| 部分支撑 | 有明确线索，但缺正式材料、连续周期或关键主体 | 当前证据支持...但暂不支持... |
| 待核验 | 有线索，但来源单一或事实链不完整 | 该议题进入核验清单 |
| 不支撑 | 样本或证据不足以形成判断 | 本期不支持将其定性为... |

## 3. 五类分析依据

分析依据主要用于内部分析或附录复核。正文只输出对读者有用的建议。

| 依据类型 | 观察项 | 作用 |
|---------|------|------|
| 主体承接 | 关键企业、机构、专家、媒体、KOL承接议题 | 判断议题是否从单点讨论进入多主体承接 |
| 关键语义 | 风险、机会、变革、冲突等关键表达 | 判断议题是否向重要方向转化 |
| 扩散持续性 | 跨平台重复、连续周期、多个高互动账号承接 | 判断议题是否具备持续扩散条件 |
| 场景进入 | 线下活动、行业会议、正式报告使用相关议题 | 判断线上议题是否进入线下或正式场景 |
| 事实材料 | 文件、数据、公告、研究报告、权威来源 | 判断是否具备进一步核验基础 |

## 4. 结构化分析习惯

生成或审查报告时，主动检查：

- 是否考虑替代解释；
- 是否区分事实、判断、推断和建议；
- 是否标注证据缺口；
- 是否说明信心和不确定性；
- 是否避免将讨论量、浏览量解释为市场信号；
- 是否避免将风险信号写成事实定性；
- 是否把反面边界放在合适位置。

## 5. 专题研判状态

| 状态 | 定义 | 报告写法 |
|------|------|---------|
| 常规监测 | 证据不足或议题尚未形成明确路径 | 维持常规监测 |
| 核验清单 | 有信号，但缺事实链或权威材料 | 进入核验清单 |
| 专题准备 | 多主体承接或关键信号出现，可能影响判断 | 建议进入专题准备 |
| 专题研判 | 已有连续承接、场景进入或关键事实材料 | 建议进入专题研判 |

## 6. 反问报告初衷

写完后用以下问题自检：

1. 读者打开第一页能否知道本期最重要的发现？
2. 每个章节是否回答了一个真实决策问题？
3. 强判断是否能追溯到原始证据？
4. 文字是否像给决策者的简报，而不是给系统看的执行日志？
5. 有哪些判断当前不能成立，是否已经降级？
6. 表格是否帮助比较，而不是替代分析？
