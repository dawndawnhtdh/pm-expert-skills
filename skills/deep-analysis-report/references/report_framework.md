# 通用分析报告框架

本框架适用于商业分析、行业研究、战略咨询、竞争分析、风险评估等场景。实际使用时可删减章节，但不能破坏"判断 -> 分析 -> 监测 -> 审计"的阅读流。

## 1. 基础信息

```text
报告主题：
报告周期：
分析对象：
数据范围：
目标读者：
报告定位：
```

报告定位建议写成一段短文，说明本报告用于识别态势、格局、风险、证据缺口和研判线索；不用于事实最终定性、决策替代或正式处置方案。

## 2. 综合研判

综合研判不默认使用表格。建议用3-5段正式分析文本：

```text
判断句。
为什么重要。
证据共同说明什么。
对分析对象或决策主体的影响。
哪些判断仍需核验或不能升级。
（证据：E-001，短说明；E-002，短说明）
```

可在综合研判后放一个轻量矩阵，但矩阵不能替代研判文本。

## 3. 格局分析

适用于企业、竞品、行业、国家、议题或风险对象。

推荐顺序：

```text
总体判断段落
  -> 格局阶段与影响对象
  -> 对象态势表
  -> 分析主体当前问题或机会
  -> 关键线索图谱
  -> 地区/人群线索
  -> 国际化线索（仅有证据时输出）
  -> 支撑数据剖面
```

支撑数据剖面应放在有效结论之后。不要先展示一堆统计，再让读者自己猜结论。

## 4. 重点议题与风险

先用分析段说明本期议题排序逻辑，再用表格压缩比较。

建议字段：

| 议题/风险 | 当前阶段 | 影响对象 | 证据说明 | 决策参考 | 证据缺口 |
|-----------|---------|---------|---------|---------|---------|

字段命名要稳定：同一分析维度不要在不同表格中换名。常用统一口径：

- "证据说明"：证据如何支撑判断；
- "决策参考"：该判断对读者有什么意义；
- "建议"：监测、补证、核验或专题准备；
- "证据缺口"：当前不能判断什么。

## 5. 判断边界

建议写法：

```text
现有材料显示{已经发生/形成/被承接的事项}，但仍缺少{正式材料/线下核验/连续周期数据/权威来源}，本期不宜进一步推断为{不能成立的判断}。
```

不要写成"本节用于避免误读""模型可判断/不可判断"或"当前数据可支持/暂不支持"的后台说明。若需要表格，表头使用"当前材料能够说明/当前材料尚不能说明"。

## 6. 验证分析

本章回答：前文判断是否有足够的数据和证据支撑。

建议字段：

| 对象/议题 | 前文判断 | 数据依据 | 验证证据 | 判断强度 | 解释边界 |
|-----------|---------|---------|---------|---------|---------|

"判断强度"只表示当前证据对前文判断的支撑程度，可用"支撑、部分支撑、不支撑、待核验"。

## 7. 专题研判与建议

本章回答：哪些议题需要进入专题准备，哪些只需核验，哪些维持常规关注。

正文应先用段落说明，不要直接甩表。

建议字段：

| 议题 | 当前状态 | 关注度 | 敏感性 | 证据完整性 | 专题研判状态 | 复核优先级 | 决策参考 | 核心缺口 |
|------|---------|--------|--------|-----------|-------------|-----------|---------|---------|

下一周期建议字段：

| 建议事项 | 研判目标 | 关注信号 | 补充数据需求 |
|---------|---------|---------|-------------|

## 8. 附录

建议附录：

```text
附录A：结论-证据映射
附录B：证据包展开
附录C：原始来源清单
附录D：分析加工过程
附录E：指标定义、口径、数据来源与处理说明
```

附录E可包含：

- 指标定义；
- 图表和表格口径；
- 数据来源与完整性说明；
- 行业或市场基线；
- 外部来源链接；
- 专题研判框架口径；
- 本期不建议升级或定性的事项。
