# 测试用例模板

## 格式说明

每个 skill 在发布前必须编写测试用例，覆盖正常路径、边界情况和错误处理。

### 标准用例格式

```markdown
### TC-{编号}：{场景名称}

- 输入：{典型输入}
- 预期输出：{期望结果}
- 验证方法：{怎么验证}
- 状态：☐ 通过 ☐ 未通过

### TC-{编号}：{场景名称}

- 输入：{异常或边界输入}
- 预期输出：{期望的错误处理}
- 验证方法：{怎么验证}
- 状态：☐ 通过 ☐ 未通过
```

### Golden Case 格式（关键验收场景）

```
## G-{编号}：{场景名称}

| 项目 | 内容 |
|------|------|
| 输入 | {描述输入} |
| 期望输出 | {描述期望输出} |
| 验收标准 | {评分维度 ≥分数} |
| 特别检查 | {需要额外验证的事项} |
```

## 用例覆盖要求

| 类型 | 最少数量 | 说明 |
|------|---------|------|
| 正常路径 | 3 | 覆盖核心功能 |
| 边界情况 | 3 | 极端输入、空值、最大长度 |
| 错误处理 | 2 | 无效输入、缺少必要参数 |
| 风险场景 | 2 | 潜在的误用或歧义 |
| **总计** | **≥10** | 通过率 100%（P0/P1）才能发布 |
