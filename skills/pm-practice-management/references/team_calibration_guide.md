# 团队校准机制

## 什么时候需要校准

| 触发条件 | 操作 |
|---------|------|
| 新成员加入 | 一次校准会议 |
| 新规则启用 | 一次校准会议 |
| 两人评分不一致 | 分歧仲裁 |
| 质量趋势异常 | 校准会议 |
| 每 sprint | 质量趋势追踪 |

## 校准会议流程

```
1. 选取 3-5 份典型文档（好/中/差各等级）
2. 每人独立评分
3. 对比差异，分差 >1 级的门禁重点讨论
4. 修正准则措辞
5. 记录到准则改进日志
```

## 分歧仲裁

```
两人分歧 → 第三人独立评分 → 取中位数 → 分歧记录到准则改进日志
```

## 质量趋势追踪

| 周期 | 平均等级 | P0/P1 数量 | 主要问题类型 |
|------|---------|-----------|-------------|
| Sprint 1 | B | 3 | ANA, EVD |
| Sprint 2 | B+ | 2 | EVD, WRT |
| Sprint 3 | A- | 1 | WRT |

## 准则改进日志

每次校准后，记录：

- 变更内容
- 变更原因
- 涉及的 Gate ID
- 生效版本
