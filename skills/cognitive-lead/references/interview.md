# 访谈

## 顺序（不能换）

1. **真实例子**：「上一次发生这件事，从头到尾是什么过程？」
2. **代价**：「那一次最难受的是哪一下？」
3. **边界**：「这次明确不解决什么？」
4. **验收**：「什么现象出现，你会说成了？什么现象出现，你会说还是不对？」
5. **盲区**：用判断句提，不用问句 —— 「我判断 X，因为 Y。这条对吗？」

前四步拿到事实，第五步才给认知。顺序反了就是盘问。

## 六类问题（按需取，不要一次全上）

| 类型 | 用途 | 例句 |
|---|---|---|
| 澄清定义 | 同一个词两边理解不同 | 「你说的『落地』，具体指哪一种？举一个算、一个不算」 |
| 追问预设 | 用户把假设当事实 | 「这件事成立的前提是什么？如果这个前提不成立呢？」 |
| 追问证据 | 判断没有依据 | 「这个结论是从哪看到的？」 |
| 换视角 | 只看自己一侧 | 「你的上级会怎么看这件事？开发会怎么理解？」 |
| 推演后果 | 只看眼前 | 「如果按这个做，三个月后会怎样？」 |
| 反问问题本身 | 问题问错了 | 「你要解决的是 X，还是 X 背后的 Y？」 |

## 禁则

- **不给选项**。选项只用于收敛，且必须带立场：「我选 A，因为……；选 B 的代价是……」
- **不预设答案**。问完停嘴，不接「是不是……对吧」。
- **一次不超过 3 问**。超了分批，先问能推翻方案的那几个。
- **不问能查到的**。文件在哪、有几个版本，自己查。
- **「随便」「都行」不当通过**。给默认值 + 它在什么情况下会错。
- **不解释每个问题为什么问**。那是我的思考过程，不是他的信息。

## 什么时候停

三个条件同时满足就停：

1. 我能复述成功标准，且他没否认
2. 我能说出不做清单
3. 关键假设都有「确认」或「接受风险」的标记

停不下来，说明前四步有一步没拿到事实。
