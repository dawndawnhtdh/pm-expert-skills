# 校准

## 置信度分档

不许写「很可能」「基本确定」。只写百分比，按档取：

| 档 | 什么情况下用 |
|---|---|
| 50% | 纯猜，正反证据差不多 |
| 60–70% | 有间接证据，但没直接看到 |
| 80–85% | 有直接证据，但样本少或来源单一 |
| 90–95% | 多个独立来源一致，或已在同类事上验证过 |
| >95% | 几乎不说。说了就要接受被记为过度自信 |

判断力不是"说得准"，是**说的概率和实际发生率对得上**。所以每一条判断都要能进日志、能回填、能算分。

## 预演失败（反例的标准生产方法）

假设这件事**已经失败了**，再倒推原因。比"想想风险"有效，因为它绕开了乐观。

四问：

1. 半年后它失败了，最直接的原因是什么？
2. 谁最先发现？他当时会说什么？
3. 我们当时忽略了哪个信号？
4. 如果只能防一个，防哪个？

## 反例的三种写法

| 类型 | 句式 | 例 |
|---|---|---|
| 结果反例 | 出现 X 现象 = 失败 | 「他问预算和排期 = 没被说服」 |
| 条件反例 | 在 X 条件下不成立 | 「只有结论错了要有人负责时，这套才成立」 |
| 时间反例 | 到 X 时间没发生 = 失败 | 「三个月后还在停下来复盘 = 失败」 |

至少给一个，最好给"结果反例"，因为它能被当场观察。

## 复查

每条判断写进日志时，同时定一个复查日：

- 短期决策：2–4 周
- 中期：3 个月
- 结构性判断：6 个月

到期回填「成立 / 不成立 / 部分成立」，不要写"差不多"。

## 校准分

用 Brier 分：每条 `(置信度 - 实际结果)²`，取平均，越低越好。

- 0.25 以下：可用
- 0.25–0.4：偏自信或偏保守，看偏差方向
- 0.4 以上：置信度不可信，先别用它做决定

分数不是给自己看的，是给用户判断"该不该信这条建议"用的。
