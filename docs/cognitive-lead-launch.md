# cognitive-lead 发布推广文案

## GitHub Release

**标题**

`cognitive-lead v1.0.0: 先校准输入，再开始产出`

**正文**

AI 很快就能开始写方案，但目标、依据和边界经常还没说清。`cognitive-lead` 是一个面向决策、方案设计和对外表达任务的 agent skill：先核对材料来源，再给出带置信度和反例的判断，最后把输入整理成可观察的验收标准。

包含证据核对、开放式访谈、判断校准、表达规范，以及可选的决策日志脚本。可单独使用，也可与本仓库的分析、质量检查和项目管理 skills 配合。

查看 [安装与使用说明](../README.md#-快速开始) 和 [Skill 文件](../skills/cognitive-lead/SKILL.md)。

### English

AI can draft quickly. The harder part is making sure the goal, evidence, and boundaries are clear first.

`cognitive-lead` is an agent skill for decision-making, solution design, and external communication. It checks evidence, states confidence and counterexamples, then turns the request into observable acceptance criteria.
